# 纯IM系统需求分析文档

## 一、项目概述

### 1.1 项目背景
基于DeepTalk项目精简，去除所有AI相关功能，保留核心IM（即时通讯）功能，实现一个类似QQ/微信的聊天系统。

### 1.2 目标用户
- 小型团队（50-200人）
- 企业内部沟通（200-500人）
- 社区/兴趣群组（500-1000人）

### 1.3 性能目标
| 指标 | 目标值 |
|------|--------|
| 同时在线用户 | 1000人 |
| 消息吞吐量 | 50条/秒 |
| 单用户群组数 | 不限制 |
| 消息延迟 | <500ms |

## 二、功能需求

### 2.1 用户管理模块

#### 2.1.1 用户注册
| 功能项 | 描述 |
|--------|------|
| 邮箱注册 | 用户通过邮箱+密码注册，需验证码 |
| 手机注册 | 用户通过手机号+验证码注册（自动登录） |
| 临时访客 | 无需注册，直接进入群聊（生成临时用户） |
| 用户信息 | 用户名、头像、手机号、邮箱 |

#### 2.1.2 用户登录
| 功能项 | 描述 |
|--------|------|
| 邮箱密码登录 | 传统账号密码登录 |
| 手机验证码登录 | 手机号+验证码快速登录 |
| Token认证 | JWT Token，有效期7天 |
| 多设备登录 | 同一用户可多设备同时在线 |

#### 2.1.3 用户信息管理
| 功能项 | 描述 |
|--------|------|
| 修改用户名 | 用户可修改自己的用户名 |
| 修改手机号 | 用户可修改绑定手机号 |
| 上传头像 | 用户可上传/更换头像 |
| 注销账户 | 用户可注销自己的账户 |

### 2.2 好友系统模块

#### 2.2.1 好友关系
| 功能项 | 描述 |
|--------|------|
| 搜索用户 | 通过用户名/手机号/邮箱搜索用户 |
| 发送好友请求 | 向其他用户发送好友请求 |
| 接受/拒绝请求 | 处理收到的好友请求 |
| 删除好友 | 从好友列表移除好友 |
| 查看好友列表 | 分页查看好友列表，支持搜索 |

#### 2.2.2 好友请求通知
| 功能项 | 描述 |
|--------|------|
| 实时通知 | WebSocket推送好友请求通知 |
| 请求数量统计 | 显示待处理好友请求数量 |

### 2.3 群组管理模块

#### 2.3.1 群组创建
| 功能项 | 描述 |
|--------|------|
| 创建群聊 | 用户创建多人群聊，设置群名 |

#### 2.3.3 群组信息管理

|--------|------|

## 四、数据模型设计

### 4.1 用户模型（User）
```
字段：
- id: 用户唯一ID（UUID）
- username: 用户名
- email: 邮箱（可选）
- phone: 手机号（可选）
- hashed_password: 密码哈希
- avatar: 头像文件ID
- is_active: 是否激活
- is_temp_user: 是否临时用户
- friends: 好友ID列表
- friend_requests: 好友请求列表
- created_at: 创建时间
```

### 4.2 群组模型（Group）
```
字段：
- id: 群组唯一ID（UUID）
- name: 群组名称
- owner_id: 群主ID
- member_ids: 成员ID列表
- type: 类型（group/private）
- last_message: 最新消息
- is_dissolved: 是否已解散
- created_at: 创建时间
```

### 4.3 消息模型（Message）
```
字段：
- id: 消息唯一ID（UUID）
- type: 消息类型（text/image/audio/file等）
- content: 消息内容
- sender_id: 发送者ID
- sender_username: 发送者用户名
- sender_avatar: 发送者头像
- group_id: 所属群组ID
- cite: 引用消息信息
- at_list: @成员列表
- read_list: 已读成员列表
- is_revoke: 是否已撤回
- is_deleted: 是否已删除
- created_at: 创建时间
- duration: 语音时长（可选）
```

### 4.4 文件模型（File）
```
字段：
- id: 文件唯一ID（UUID）
- file_name: 文件名
- file_type: 文件类型
- file_size: 文件大小
- local_file_path: 本地存储路径
- owner_id: 上传者ID
- group_id: 所属群组ID（可选）
- is_deleted: 是否已删除
- created_at: 创建时间
```

## 八、验收标准

### 8.1 功能验收
- 用户可以注册、登录、注销
- 用户可以创建群组、私聊
- 用户可以发送文本消息，其他人实时收到
- 用户可以撤回、删除自己的消息
- 用户可以添加好友、处理好友请求
- 用户可以上传头像、群组文件
- 断线重连后可以获取离线消息

### 8.2 性能验收
- 1000人同时在线不崩溃
- 消息延迟小于500ms
- 消息发送成功率99%+

### 8.3 安全验收
- 未登录用户无法访问受保护接口
- 非群成员无法查看群消息
- Token过期后无法继续使用
