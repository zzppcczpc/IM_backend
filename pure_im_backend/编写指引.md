## 第4步：安全与认证模块

### 4.1 创建 utils/security.py

**功能**: 密码哈希、Token生成

**核心代码思路**:
```python
import bcrypt
from jose import jwt
from datetime import datetime, timedelta

ALGORITHM = "HS256"

def verify_password(plain_password: str, hashed_password: str) -> bool:
    """验证密码"""
    return bcrypt.checkpw(
        plain_password.encode(), 
        hashed_password.encode()
    )

def get_password_hash(password: str) -> str:
    """哈希密码"""
    return bcrypt.hashpw(
        password.encode(), 
        bcrypt.gensalt()
    ).decode()

def create_access_token(data: dict) -> str:
    """生成JWT Token"""
    expire = datetime.utcnow() + timedelta(days=7)
    data.update({"exp": expire})
    return jwt.encode(data, settings.SECRET_KEY, ALGORITHM)
```

### 4.2 创建 utils/auth.py

**功能**: 获取当前用户依赖

**核心代码思路**:
```python
from fastapi import Depends, HTTPException
from fastapi.security import OAuth2PasswordBearer
from jose import JWTError, jwt

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="api/auth/login")

async def get_current_user(token: str = Depends(oauth2_scheme)):
    """从Token解析当前用户"""
    try:
        payload = jwt.decode(token, settings.SECRET_KEY, ALGORITHM)
        user_id = payload.get("uuid")
    except JWTError:
        raise HTTPException(401, "无效Token")
    
    # 查询用户
    db = await get_database()
    user = await db.users.find_one({"id": user_id, "is_active": True})
    if not user:
        raise HTTPException(401, "用户不存在")
    
    return User(**user)
```

## 第5步：WebSocket管理器

### 5.1 创建 utils/websocket_manager.py

**功能**: 管理所有WebSocket连接，实现消息广播

**核心代码思路**:
```python
import asyncio
from fastapi import WebSocket

class ConnectionManager:
    def __init__(self):
        self.active_connections: dict = {}  # user_id -> [websocket列表]
        self.lock = asyncio.Lock()
    
    async def connect(self, user, websocket):
        """用户连接"""
        await websocket.accept()
        async with self.lock:
            if user.id not in self.active_connections:
                self.active_connections[user.id] = []
            self.active_connections[user.id].append(websocket)
    
    async def disconnect(self, user_id, websocket):
        """用户断开"""
        async with self.lock:
            self.active_connections[user_id].remove(websocket)
    
    async def broadcast(self, user_list: list, message: str):
        """广播给多个用户"""
        for user_id in user_list:
            connections = self.active_connections.get(user_id)
            if connections:
                for conn in connections:
                    await conn.send_text(message)

connection_manager = ConnectionManager()
```

**注意事项**:
- 使用锁保证线程安全
- 支持同一用户多设备

### 11.1 创建 routes/chat.py

**这是最核心的部分！**

#### 核心函数：消息广播

```python
async def broadcast_message(group_id: str, message: Message, manage_db):
    """广播消息给群组所有成员"""
    # 1. 获取群组成员列表
    group = await manage_db.groups.find_one({"id": group_id})
    member_ids = group["member_ids"]
    
    # 2. 构建广播数据
    broadcast_data = json.dumps({
        "type": "message",
        "group_id": group_id,  # 重要：标识消息来源
        "data": message.model_dump()
    })
    
    # 3. 广播给所有在线成员
    await connection_manager.broadcast(member_ids, broadcast_data)
```

#### WebSocket端点：正式用户

```python
@router.websocket("/ws/{token}")
async def websocket_endpoint(websocket: WebSocket, token: str):
    """正式用户WebSocket"""
    # 1. 验证用户
    user = await get_current_user(token)
    
    # 2. 连接管理器
    await connection_manager.connect(user, websocket)
    
    # 3. 查询用户所有群组（关键：多群订阅）
    groups = await db.groups.find({"member_ids": user.id}).to_list()
    
    # 4. 发送连接确认（包含所有群组信息）
    await websocket.send_json({
        "type": "connected",
        "content": {
            "user_id": user.id,
            "groups": [...],  # 所有群组列表
        }
    })
    
    # 5. 消息循环
    while True:
        data = await websocket.receive_json()
        
        if data["type"] == "ping":
            await websocket.send_json({"type": "pong"})
        
        elif data["type"] == "send_message":
            # 创建消息
            message = await create_message(...)
            # 广播消息
            await broadcast_message(data["group_id"], message)
            # 发送确认
            await websocket.send_json({"type": "message_sent"})
        
        elif data["type"] == "revoke":
            # 撤回处理
            ...
```

**注意事项**:
- 一个WebSocket连接处理所有群组消息
- 消息必须带group_id区分来源
- 发送消息后要有确认

## 附录：关键代码模板

### A. 消息创建与广播完整流程

```python
async def handle_send_message(websocket, data, user, db):
    """处理发送消息"""
    # 1. 获取参数
    group_id = data["group_id"]
    content = data["content"]
    
    # 2. 创建消息对象
    message = Message(
        type="text",
        content=content,
        sender_id=user.id,
        sender_username=user.username,
        group_id=group_id,
    )
    
    # 3. 保存到数据库
    chat_collection = getattr(chat_db, group_id)
    await chat_collection.insert_one(message.model_dump())
    
    # 4. 更新群组最新消息
    await manage_db.groups.update_one(
        {"id": group_id},
        {"$set": {"last_message": message.model_dump()}}
    )
    
    # 5. 广播给群组所有成员
    group = await manage_db.groups.find_one({"id": group_id})
    broadcast_data = json.dumps({
        "type": "message",
        "group_id": group_id,
        "data": message.model_dump()
    })
    await connection_manager.broadcast(group["member_ids"], broadcast_data)
    
    # 6. 发送确认给发送者
    await websocket.send_json({
        "type": "message_sent",
        "content": {"message_id": message.id, "success": True}
    })
```

## 常见问题

### Q1: WebSocket连接后收不到消息？
检查：
- 是否正确订阅了群组
- 广播时group_id是否正确传递
- ConnectionManager是否正确记录连接

### Q2: 消息发送后没有确认？
检查：
- 是否在创建消息后发送了确认
- WebSocket是否还在连接状态

### Q3: 多设备登录问题？
检查：
- ConnectionManager是否用列表存储多连接
- disconnect是否正确移除
